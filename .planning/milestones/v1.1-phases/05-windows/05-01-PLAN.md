Create scripts/notify-play.ps1 -- a PowerShell 5.1 compatible script that plays an MP3 notification with 5-second per-type cooldown debounce. Mirror the behavior of notify-play.sh exactly.

Script structure:

1. **Parameters** (per D-01, PS 5.1 compatible param block):
   ```powershell
   param(
       [Parameter(Mandatory=$true)][string]$Type,
       [Parameter(Mandatory=Mandatory=$true)][string]$AudioFile
   )
   ```

2. **Strict mode + error handling**:
   ```powershell
   $ErrorActionPreference = "Stop"
   ```
   All audio logic MUST be wrapped in try/catch that always exits 0 (per RESEARCH Pitfall 6: Stop/SubagentStop hooks block on non-zero exit).

3. **Cooldown debounce** (per D-03, mirrors notify-play.sh lines 14-28):
   - Lock file path: `Join-Path $env:TEMP "claude-notify-$Type.lock"`
   - If lock file exists, compute age: `$lockAge = ((Get-Date) - (Get-Item $LockFile).LastWriteTime).TotalSeconds`
   - If `$lockAge -lt 5`, exit 0 immediately (within cooldown window, skip playback)
   - Fallback if $env:TEMP is empty: use `[System.IO.Path]::GetTempPath()` per RESEARCH Open Question 4
   - Update lock timestamp: `Set-Content -Path $LockFile -Value (Get-Date).ToString() -NoNewline`

4. **Audio playback** (per D-02, RESEARCH Pattern 1):
   ```powershell
   try {
       Add-Type -AssemblyName PresentationCore
       $player = New-Object System.Windows.Media.MediaPlayer
       $player.Open([System.Uri]::new($AudioFile))
       Start-Sleep -Milliseconds 500  # Wait for media to load
       $player.Play()
       # Wait for playback to finish (per RESEARCH Pitfall 3: script must not exit before playback completes)
       while ($player.NaturalDuration.HasTimeSpan -and $player.Position -lt $player.NaturalDuration.TimeSpan) {
           Start-Sleep -Milliseconds 100
       }
       $player.Close()
   } catch {
       # Silently ignore all errors -- hook must never block Claude
   }
   exit 0
   ```

5. **Critical constraints**:
   - ALWAYS exit 0, even on errors (wrap everything in try/catch)
   - DO NOT load PresentationFramework (only PresentationCore needed)
   - DO NOT use WMPlayer.OCX COM object
   - MediaPlayer.Play() is non-blocking, MUST wait in while-loop for NaturalDuration completion (per Pitfall 3)
   - Check NaturalDuration.HasTimeSpan before accessing .TimeSpan (may not be available immediately after Open)
  </action>

  </verify>
