**Step 1: Run the Docker container with volume mounts**

```bash
docker run --rm \
    --user $(id -u):$(id -g) \
    -v ~/.cache/spark-tts/:/app/pretrained_models/Spark-TTS-0.5B:z \
    -v ~/.claude/:/output/:z \
    spark-tts-notify
```

This will:
1. Auto-download Spark-TTS-0.5B model (~3.95GB) on first run to ~/.cache/spark-tts/ (D-02)
2. Load model onto CPU device
3. Generate 4 WAV files using voice creation mode (female, low pitch, low speed)
4. Convert each WAV to MP3 via ffmpeg
5. Output mp3 files to ~/.claude/ via volume mount

IMPORTANT: CPU inference takes approximately 8 minutes per sentence. Total runtime is approximately 32 minutes for all 4 notifications. The first run also includes ~3.95GB model download time. Use a long timeout for this command.

The `docker run` timeout should be set to at least 600000ms (10 minutes) or run in background with monitoring. Given the total expected time of 30-40 minutes (download + inference), consider running with an appropriate timeout.
