  <action>
    Create generate.sh with the following exact structure. This script implements SCRIPT-01 (full pipeline), SCRIPT-02 (verification), and SCRIPT-03 (selective generation passthrough).

    ```bash
    #!/usr/bin/env bash
    set -euo pipefail
    ```

    **Variables section** (after set -euo pipefail):
    - IMAGE_NAME="spark-tts-notify"
    - SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)" (per Pitfall 3 -- absolute paths)
    - MODEL_DIR="$HOME/.cache/spark-tts"
    - OUTPUT_DIR="$HOME/.claude"

    **Error trap** (per D-08):
    ```bash
    trap 'echo "错误：脚本执行失败，请检查上方输出" >&2' ERR
    ```

    **Help function** (per D-09 -- Chinese help):
    Print usage showing:
    - Script purpose: "Claude Code 语音通知生成脚本"
    - Usage: ./generate.sh [选项]
    - Options: --type/-t (comma-separated types), --force-rebuild, --help/-h
    - Available types: complete, confirm, error, progress
    - Examples: ./generate.sh, ./generate.sh --type confirm,error, ./generate.sh --force-rebuild

    **Argument parsing** (per D-04, D-02):
    Parse --force-rebuild (sets FORCE_REBUILD=true), --type/-t (sets NOTIFY_TYPES to next argument), --help/-h (print help and exit 0), unknown args (print error and exit 1).

    **Step 1: Docker build** (per D-03, D-04):
    - If FORCE_REBUILD=true: print "==> 强制重建 Docker 镜像..." then `docker build -t "$IMAGE_NAME" "$SCRIPT_DIR"` (NOT --no-cache, per anti-pattern in research)
    - Elif `docker image inspect "$IMAGE_NAME" &>/dev/null`: print "==> Docker 镜像已存在，跳过构建"
    - Else: print "==> Docker 镜像不存在，开始构建..." then `docker build -t "$IMAGE_NAME" "$SCRIPT_DIR"`

    **Step 2: Model directory** (ensure it exists before docker run):
    - `mkdir -p "$MODEL_DIR"` so Docker can mount it

    **Step 3: Run TTS generation** (per established Phase 1 pattern):
    ```bash
    DOCKER_ARGS=(
        --rm
        --user "$(id -u):$(id -g)"
        -v "$MODEL_DIR:/app/pretrained_models/Spark-TTS-0.5B:z"
        -v "$OUTPUT_DIR:/output:z"
    )
    ```
    - If NOTIFY_TYPES is not empty: append `--env GENERATE_TYPES="$NOTIFY_TYPES"` to DOCKER_ARGS
    - Print "==> 开始生成通知音频..." (or "==> 开始生成通知音频: $NOTIFY_TYPES..." if selective)
    - Run `docker run "${DOCKER_ARGS[@]}" "$IMAGE_NAME"`

    **Step 4: Verify output** (per D-05, D-06):
    Define verify_output() function:
    ```bash
    verify_output() {
        local name="$1"
        local filepath="$OUTPUT_DIR/notify-${name}.mp3"
        if [[ ! -f "$filepath" ]]; then
            echo "  [FAIL] notify-${name}.mp3 -- 文件不存在"
            return 1
        fi
        if ! file "$filepath" | grep -qi "MPEG.*layer III"; then
            echo "  [FAIL] notify-${name}.mp3 -- 文件格式无效"
            file "$filepath"
            return 1
        fi
        echo "  [OK] notify-${name}.mp3"
    }
    ```
    Determine which types to verify:
    - If NOTIFY_TYPES is set: split by comma into array VERIFY_TYPES
    - Else: VERIFY_TYPES=(complete confirm error progress)
    Print "==> 验证输出文件..." then loop over VERIFY_TYPES calling verify_output for each.
    Print "==> 验证通过" after all pass.

    **Final message:**
    Print "==> 全部完成！" after successful verification.

    **After creating the file**, make it executable: `chmod +x generate.sh`
  </action>
