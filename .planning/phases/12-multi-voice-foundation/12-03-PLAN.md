If Docker is not running, the task cannot proceed. If the model cache is missing, it will be auto-downloaded inside the container (may take additional time).

**Step 2: Run generation**

Execute the generation command:
```bash

./generate.sh --voice deep
```

This will:
1. Build the Docker image if not present (copies voices/ into image per Dockerfile update)
2. Run generate.py inside Docker with GENERATE_VOICE=deep env var
3. generate.py loads voices/deep.json (gender=male, pitch=high, speed=moderate)
4. Generates 4 sentences sequentially (expect ~30 min total on CPU)
5. Output goes to audio/voices/deep/ (via OUTPUT_DIR override in generate.sh)
6. verify_output() confirms each file is valid MPEG audio
